# elisha-videos

Public website for **Elisha-videos**, a personal short-video studio that turns long gameplay videos into
9:16 shorts and publishes them to the owner's own TikTok and YouTube accounts.

- `index.html`: overview, screenshots and example clips
- `app.html`: the app's front-end (works only with the local server on the owner's computer)
- `legal/terms.html`: Terms of Service
- `legal/privacy.html`: Privacy Policy
- `videos/`: example shorts (compressed)

The editing engine and API integrations run locally and are not part of this repository.
